# پروفایل‌ها (آواتار و قاب)

هر فایل PNG که اینجا بگذارید، در اولین اجرای نسخه‌ی بعدی برنامه خودکار به‌صورت آیتم رایگان در فروشگاه و گنجینه‌ی اعضا ثبت می‌شود.

## اسم فایل
- آواتار: `avatar_<نام>.png`
- قاب: `frame_<نام>.png`

نام فقط حروف کوچک انگلیسی و عدد است؛ بین کلمه‌ها یک `_`. فاصله و پرانتز، مثل `frame_ghadir (1).png`، پذیرفته نمی‌شود.

| نام فارسی | نام در فایل |
|---|---|
| رهبر شهید | `leader` |
| شهید قاسم سلیمانی | `soleimani` |
| ذوالفقار | `zulfiqar` |
| ماه رمضان | `ramadan` |
| غدیر | `ghadir` |
| فاطمیه | `fatemiyeh` |
| تکاور | `commando` |
| ارتشی | `army` |

مثال: `frame_zulfiqar.png` ← «قاب ذوالفقار»، `avatar_commando.png` ← «آواتار تکاور».
نام دیگری هم قبول می‌شود و همان نام انگلیسی در برنامه نشان داده می‌شود.

## شرط تصویر
- PNG مربع با پس‌زمینه‌ی شفاف، بهتر است ۵۱۲×۵۱۲ و هر فایل زیر حدود ۵۰۰ کیلوبایت.
- **قاب:** وسطش یک دایره‌ی کاملاً شفاف و دقیقاً در مرکز باشد. چیز نیمه‌شفافِ دیدنی داخل دایره آواتار را کوچک می‌کند.
- **آواتار:** سوژه وسط باشد و داخل دایره بماند؛ گوشه‌ها به شکل دایره بریده می‌شوند.

جایگزین‌کردن یک فایل با همان نام، تصویر را در برنامه به‌روز می‌کند. آیتمی که در فروشگاه حذف کنید دوباره برنمی‌گردد.
