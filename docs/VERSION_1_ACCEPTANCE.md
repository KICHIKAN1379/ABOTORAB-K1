# معیارهای پذیرش نسخهٔ اول AK1 — مربی ابوتراب

## هدف نسخه
نسخهٔ اول باید برای کار روزمرهٔ مربی بدون اینترنت و بدون ورود به حساب گوگل قابل استفاده باشد. اطلاعات اصلی روی همان دستگاه نگهداری می‌شوند. اتصال به گوگل، همگام‌سازی آنلاین و نقش مدیر مجموعه جزو این نسخه نیستند.

## موارد پیاده‌سازی‌شده در این مرحله
- نگهداری محلی اطلاعات حلقه، اعضا، اقتصاد، تاریخچه، فروشگاه، گردونه، مأموریت‌ها، جلسه‌ها، حضور و غیاب، گروه‌ها و دارایی‌های سفارشی.
- انتقال عضو حذف‌شده به «اعضای حذف‌شده» به‌جای پاک‌کردن فوری اطلاعات او.
- امکان بازیابی عضو با همان شناسه و حفظ تاریخچه، حضور و غیاب، جلسه‌ها و پیوندهای گروهی.
- حذف دائمی عضو فقط از طریق تأیید جداگانه؛ این عملیات سوابق وابسته را نیز پاک می‌کند.
- خروجی و ورود دستی فایل JSON از طریق انتخاب‌گر فایل اندروید؛ بدون نیاز به حساب یا سرویس آنلاین.
- گنجاندن تنظیمات برنامه و تصاویر فروشگاه/دارایی‌ها در پشتیبان تا سقف ۱۰ مگابایت برای هر تصویر.
- اعتبارسنجی ساختار پشتیبان پیش از بازیابی دارایی‌ها؛ فایل نامعتبر نباید تصاویر فعلی را بازنویسی کند.
- پشتیبانی از فایل‌های پشتیبان قدیمی‌تر (schema نسخه‌های ۱ تا ۵) در کنار نسخهٔ ۶.

## محدودیت‌های شناخته‌شده
- تصاویر بزرگ‌تر از ۱۰ مگابایت در فایل JSON جاسازی نمی‌شوند؛ قبل از انتشار عمومی باید یا این محدودیت در رابط کاربری به‌صورت روشن کنترل شود یا ذخیره‌سازی فایل‌ها به‌صورت جداگانه طراحی شود.
- تصویر پروفایل حلقه که با URI انتخاب‌گر فایل ذخیره شده، وابسته به دستگاه/ارائه‌دهنده است و داخل پشتیبان قرار نمی‌گیرد؛ هنگام بازیابی، تصویر محلی همان دستگاه حفظ می‌شود.
- ذخیره‌سازی فعلی محلی و مبتنی بر JSON در SharedPreferences است. مهاجرت به Room می‌تواند برای داده‌های بزرگ‌تر مناسب باشد، اما باید جداگانه، با مهاجرت نسخه‌دار و آزمون حفظ اطلاعات انجام شود؛ این تغییر نباید بی‌محابا روی داده‌های موجود اعمال شود.
- پشتیبان‌گیری خودکار، اتصال گوگل، همگام‌سازی چنددستگاهی و مدیریت چند مربی عمداً در نسخهٔ اول فعال نیستند.
