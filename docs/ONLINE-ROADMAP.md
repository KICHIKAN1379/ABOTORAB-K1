# نقشه راه آنلاین AK1

## وضعیت فعلی — فاز ۱: مربی آفلاین
- این نسخه هیچ احراز هویت آنلاین، API، سرور، دیتابیس ابری یا همگام‌سازی شبکه‌ای ندارد.
- هر حلقه فقط روی دستگاه مربی نگهداری می‌شود.
- ورود/خروجی پشتیبان JSON برای انتقال داده بین دستگاه‌ها فعال است.
- نام حلقه و نام کاربری در این فاز فقط شناسه محلی هستند و حساب آنلاین محسوب نمی‌شوند.

## فاز ۲ — اپلیکیشن اعضا
پس از تثبیت اپ مربی:
- اپ مستقل اعضا ساخته می‌شود.
- قرارداد داده و شناسه‌های پایدار بین مربی و عضو تعریف می‌شود.
- مدل دسترسی عضو فقط داده‌های مجاز خودش را می‌بیند.
- اتصال آنلاین هنوز تا تکمیل فاز مدیریت فعال نمی‌شود.

## فاز ۳ — اپلیکیشن مدیر
- اپ مستقل مدیر برای مدیریت مجموعه/حلقه‌ها ساخته می‌شود.
- نقش‌ها، سطح دسترسی، ساختار مجموعه و مدیریت چندحلقه‌ای تعریف می‌شود.
- سپس backend و احراز هویت آنلاین به صورت واقعی طراحی و پیاده‌سازی می‌شوند.
- مهاجرت از داده محلی به داده ابری با نسخه‌بندی schema انجام می‌شود.

## فاز ۴ — فعال‌سازی آنلاین
فقط بعد از آماده‌شدن اپ مربی + اعضا + مدیر:
- backend production
- احراز هویت
- API امن
- sync و conflict resolution
- backup ابری
- مدیریت دسترسی و audit log
- مهاجرت امن داده‌های آفلاین

## فاز ۵ — اپلیکیشن والدین
بعد از تثبیت معماری آنلاین:
- اپ والدین با دسترسی محدود و فقط به اطلاعات مجاز فرزند
- گزارش رشد، حضور، فعالیت‌ها و پاداش‌ها
- بدون دسترسی والد به داده‌های سایر اعضا یا اطلاعات داخلی مربی

### اصل معماری
**Offline-first اکنون؛ Online-later پس از ساخته‌شدن سه سطح محصول: مربی → اعضا → مدیر؛ سپس والدین.**

تا قبل از فاز ۴ هیچ UI یا کد عملیاتی نباید وانمود کند که حساب آنلاین فعال است.
